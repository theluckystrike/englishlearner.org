About this estimate

What counts as a word family

A family groups a base word with related forms. For example, help, helps and helpful belong together. Knowing one form does not prove that you know all forms.

How the words were chosen

We sampled eight headwords from each of the first five BNC/COCA frequency bands. Each band contains about 1,000 word families. Paul Nation developed these lists. See the BNC/COCA lists and their method.

How guessing changes the result

There are 40 real words and ten made-up words. For each band, we subtract the made-up Yes rate from the real-word Yes rate. We divide by one minus the made-up Yes rate. Values below zero count as zero.

We multiply each corrected rate by 1,000, then add the five bands. The displayed range extends 1,000 families below and above that total, within zero to 5,000. That is a display margin, not a measured error range.

If you mark five or more made-up words Yes, we don't give a number. That is this tool's caution rule. It is not a research cutoff.

What this short test cannot show

The yes/no method uses real words and made-up words to reduce guessing. This particular sample and correction have not been validated with learners. Your estimate may differ a lot from a longer test. It does not check speaking, listening or how well you use words.

Build on words you know

Read a short text you enjoy. Write down useful new words with a sentence. Review them later, then try using them.
